# 错题汤 Misoup — 设计定稿

> 状态：定稿（2026-08-16 拷问产出）｜License：GPL-3.0｜技术栈：Kotlin 原生 + Jetpack Compose
> 本文件是项目唯一事实源。功能增删、架构变更必须先改本文件再动代码。

---

## 1. 一句话定位

**面向学生极客群体的高质量错题本**：拍照/相册收录错题 → 智能识别结构化 → 科学复习 → 印刷级排版输出。替代手工抄题，本地优先、数据开放、完全免费。

## 2. 目标用户与差异化

- **用户**：追求高质量错题本的学生极客（初高中数理化为主，兼大学生/自学者）。懂技术、愿意折腾配置、在意隐私与可控性、是 AnkiDroid/Obsidian 类工具的受众。
- **差异化**：大众错题本（小猿/蜜蜂试卷）是"傻瓜黑盒"；Misoup 是"透明可折腾"——
  - 完全免费、无广告、开源可审计
  - 本地优先，数据是普通文件夹，用户完全掌控
  - 识别管线可配置（模型可换、Key 可自配、失败可手动修正）
  - 输出做到印刷级（LaTeX 排版 PDF）
- **非目标**：大众学生、完全零配置用户、不需要商业级支持。

## 3. 核心设计原则（"高质量"的精确定义）

| 层级 | 含义 | 落地 |
|---|---|---|
| **骨架** | 排版输出 + 数据开放 | LaTeX 级 PDF 输出；文件系统存储、JSON 明文、格式文档化 |
| **血肉** | 识别管线透明可控 | OCR/公式/结构拆分双轨（离线模型 + BYOK 视觉模型），参数可调、结果可改 |
| **细节** | 复习算法科学性 | FSRS 排期、参数可调、复习数据可导出分析 |

附加原则：
- **录入永不阻塞**：图片先落库，AI 识别后台异步补上，离线/失败不影响录入。
- **本地优先**：核心功能全离线可用；云端能力均为可选项。
- **极客可折腾**：技术细节（模型配置、日志、数据路径）对用户可见，而非隐藏。

## 4. 技术栈与工程基线

- Kotlin + Jetpack Compose，单模块起步（识别/输出复杂度上来再拆）
- `minSdk 26`（Android 8.0，PaddleOCR 兼容下限）/ `targetSdk 36`
- 原生图像管线：OpenCV（矫正/画质/形态学）+ NDK（已装 NDK 28.2）
- 离线 OCR：PaddleOCR 移动端模型（PP-OCRv4 量级），模型文件打包进 APK 或首次运行下载
- LaTeX 渲染/排版：WebView + MathJax/KaTeX → 系统 Print → PDF（原生成熟路径）
- 数据库：无黑盒 SQLite；文件系统即存储（见 §5），内存索引缓存保列表流畅
- 构建：Gradle 走阿里云/腾讯镜像（`D:\Android\templates` 模板）

## 5. 数据模型与存储（骨架：数据开放）

**每道错题 = 一个文件夹**，错题库 = 规范目录树：

```
错题库根/（用户可选，默认 App 私有目录或用户指定）
└── 数学/
    └── 20260816_140523_二次函数区间最值/
        ├── meta.json          ← 唯一事实源：标签/错因/来源/FSRS状态/备注/识别结果
        ├── 原图.jpg           ← 矫正后原图（压缩 WebP/JPEG，单题 ≤300KB）
        ├── 去手写.png         ← 可选：擦除/遮罩结果
        ├── 文本.md            ← OCR + 公式 LaTeX 混合文本（题干/答案/解析分段）
        └── 变式题/            ← 可选：AI 生成的变式题
```

- 自动命名规则：`YYYYMMDD_HHMMSS_题目摘要.md`（时间 + 科目由所在目录体现）
- 导出/备份/迁移 = 拷贝文件夹；Git 仓库天然可追踪
- 列表性能：目录扫描 + 元数据内存缓存 + 缩略图懒加载
- 搜索：`文本.md` 全文索引（内存 Trie/简单倒排，量级 ≤1 万题不引重型引擎）

**meta.json 关键字段**（定稿）：`id, 科目, 题型, 错因[], 自定义标签[], 来源, 备注, 知识点[], createdAt, updatedAt, fsrs{state, due, stability, difficulty}, 识别{engine, status}`

## 6. 功能全景（完整版 V2，40 项）

### 一、图像录入与预处理
拍摄录入 / 相册导入 / 批量导入 / 连拍模式 / 文档自动矫正（透视扶正+切边）/ 画质增强（亮度对比度阴影）/ 图片压缩 / 整页自动拆单题（V2，先连拍模式）

## 7. AI 能力策略（成本与实现路径）

| 能力 | 路径 | 成本 |
|---|---|---|
| OCR 文字 | 离线 PaddleOCR（NDK 集成） | 零 |
| 公式识别/结构拆分 | 视觉 LLM：**引导注册智谱 GLM-4V-Flash（免费）** 一键填入 + **BYOK 主推**（DeepSeek/Qwen 等，OpenAI 兼容协议） | 免费通道零（限速）；BYOK 用户自理 |
| 去手写 | 核心交互 = **遮罩/裁剪**（重做模式，零成本可靠）；真擦除 = 导出前可选按钮调百度「手写文字擦除」API（免费额度） | 零 / 限额 |
| 变式出题/答疑 | LLM 生成（免费通道引导 + BYOK） | 同上 |
| 知识点评估 | 本地规则聚合（标签统计） | 零 |

**免费通道实现**：不做内置 Key（开源即泄露）→ "一键跳转智谱注册 + 领免费 Key + 粘贴"引导流程。录入时 AI 识别后台异步、失败不阻塞（见 §3）。

## 8. 同步方案（无账号）

- **WebDAV**（坚果云免费版挂载目录即同步，双向）
- **Git**（极客用户自建私有仓库，数据目录即仓库）
- 不做账号体系、不做后端服务器、不收集手机号 —— 零服务器成本，隐私最简

## 9. 分发与商业模式

- **GitHub Releases**（开源门面，GPL-3.0）
- **国内直发**：网盘直链 / QQ 群 / 酷安动态链接（软著、APP 备案暂不办理，极客渠道足够）
- **捐赠**：爱发电（个人可开通，国内可达；GitHub Sponsors 提现难，不作为主渠道）
- 完全免费、无广告、无内购

| 期 | 交付物 | 内容 |

| **M0** | 骨架 | Gradle 工程、Compose 导航、主题、文件存储基座（目录树 + meta.json + 索引） |

| **M2** | 复习闭环 | 遮罩重做 / FSRS / 今日队列 / 学情统计 |

## 11. 合规与隐私

- 数据默认全本地，不上传任何服务器
- BYOK/免费通道场景：题目图片发送至**用户自配的第三方 API**（隐私政策明示）
- 试卷照片可能含姓名/学校（个人信息），隐私政策要点名；不收集未成年人身份信息
- 开源仓库附带 PRIVACY.md + 隐私政策页
