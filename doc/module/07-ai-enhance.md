# 模块 07 · AI 增强（M4）

> 依据：DESIGN.md §7。变式出题、题目答疑、知识点掌握度。全部走模块 05 的通道（BYOK 主推 + 免费引导）。

## 职责
- 变式出题：围绕错题考点生成新题（存 `变式/` 目录）
- 题目答疑：对话式讲解（跟随错题上下文）
- 知识点掌握度：本地聚合展示

## 变式出题
```kotlin
suspend fun generateVariants(id: String, count: Int = 2): Result<List<Variant>>
data class Variant(val title: String, val question: String, val answer: String, val hint: String?)
```
- Prompt（文本模型，无需图像）：
```
你是出题老师。基于下面的错题，出 {n} 道同考点的变式题（难度递增），只输出 JSON 数组：
[{"question":"...", "answer":"...", "hint":"..."}]
考点: {knowledgePoints} 原题: {文本.md 题干+答案}
```
- 流程：详情页"变式"按钮 → 弹窗选数量(1-3) → 生成 → 保存 `变式/yyyyMMdd_HHmmss_变式N.md` → 列表展示（可展开答案）
- 模型选择：默认文本模型（DeepSeek-chat / glm-4-flash / 用户自定义）；无 Key → 引导流程（复用模块 05 引导）

## 题目答疑
- 详情页"答疑"按钮 → 底部弹层对话（记录上下文 = 当前错题结构化内容 + 用户提问）
- Prompt 前缀：`你是耐心的高中理科老师。讲解下面这道错题，先给思路再给步骤，不要直接给答案除非用户要求。` + 错题内容
- 会话仅内存（不持久化，极客隐私友好）；支持"重讲/举例/换一种解法"

## 知识点掌握度
- 数据源：meta.knowledgePoints × reviews（模块 03 已有）
- 聚合：`mastery(kp) = Σ(该 kp 错题正确率) / 题数`，0~1；红 <0.4 / 黄 <0.7 / 绿 ≥0.7
- 展示：复习 tab"薄弱知识点"卡片（按 mastery 升序 top5）+ 知识点详情（关联错题列表，点击直达）

## 成本与限流
- 全部走用户通道；免费通道受模块 05 令牌桶约束
- 变式/答疑失败（限流/断网）→ 明确提示"AI 服务不可用"，不静默
