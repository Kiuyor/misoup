# 模块 06 · 整页拆题（M3 末）

> 依据：DESIGN.md §6/§13。最不稳定模块，排期最后；产物永远可手动修正。

## 职责
- 整页试卷照 → 拆出 N 道单题 → 批量入库（每题独立走模块 01 后续流程）

## 实现路径（启发式 + 视觉 LLM 双轨）
```
用户: 相册选整页 → 拆题页(预览+确认) → 提交
拆题 = 候选框生成(det) + 视觉LLM按框输出边界修正/合并 → 用户拖拽微调 → 确认 → 逐题入库
```
1. **候选框**（离线，OpenCV/ONNX det 复用模块 04）：文本行检测 → 行聚类（y 间距 < 阈值合并）→ 题目块（题号模式 `1.`/`(1)`/`一、` 识别为分界）→ 输出 `List<RectF>`
2. **视觉 LLM 校验**（可选增强，无 Key 跳过）：整图 + 候选框列表 → 模型输出"合并/拆分/删除"建议 + 每题边界（对两栏、插图、跨栏题有效）
3. **人工确认**：拆题页显示叠加框，可拖拽/新增/删除/合并；"开始逐题录入" → 每框走模块 01 预处理+落库

## 边界情况（设计即承认不完美）
- 两栏排版：视觉 LLM 修正为主，离线结果可作初稿
- 插图/表格题：框内保留原区域，不做版面重排
- 无法拆分的图（无题号、乱排版）：提示"未识别到题目分界，建议手动裁剪"

## 数据流
- 拆题不直接改原图；每题 = 新错题条目（来源 tag 自动带"整页拆题"）
- 拆题结果可"撤销全部"（未确认提交前）；提交后逐题独立可删

## 验收标准
- [ ] 标准单栏试卷照（题号清晰）→ 离线启发式拆分准确率 ≥70%（无需视觉 LLM）
- [ ] 视觉 LLM 增强后两栏样例可拆分（人工微调 ≤2 处/页）
- [ ] 拆题页交互：拖拽/合并/删除框无卡顿；确认后逐题入库成功
- [ ] 烂图不崩溃，明确提示走手动裁剪
