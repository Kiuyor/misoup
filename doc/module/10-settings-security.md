## 安全实现
- **凭据存储**：`EncryptedSharedPreferences`（AndroidX Security，KeyStore 加密）；WebDAV 密码 / 百度 Key / BYOK Key 全走它
- **本地数据**：明文（数据开放原则，DESIGN §11 已定）；V2 可选"导出包密码加密"（AES-GCM，密码不进文件）
- **网络**：WebDAV/LLM/百度全 HTTPS；明文 http 请求直接拦截并提示
- **日志**：不打印 Key/密码；识别失败日志含路径不含内容

## 兼容性（多 ROM / 多版本）
- minSdk 26 起：API 26-36 行为差异表（施工时核对）：
  - API 33+ `POST_NOTIFICATIONS` 运行时权限（V2 提醒用）
  - Photo Picker API 33+ / 26-32 用 `ACTION_OPEN_DOCUMENT` 回退
  - 前台服务/后台限制：vivo(OriginOS)/小米(澎湃OS)/华为 省电白名单引导页（检测 `Build.MANUFACTURER` 显示对应指引文案）
- 系统字体：中文正文用系统字体（不强制打包），LaTeX 数学符号由 KaTeX fonts 自带

## 合规
- PRIVACY.md（仓库根）：数据本地、无遥测、BYOK 时题目发往用户自配第三方 API、不收集未成年人身份信息
- 开源合规：GPL-3.0 LICENSE 文件；第三方依赖许可证清单（THIRD-PARTY-NOTICES）
